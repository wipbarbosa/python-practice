# Analisador de Palavras em Python

Este é um script em Python que solicita ao usuário a digitação de 8 palavras, realiza análises estatísticas sobre elas e exibe um resumo detalhado dos dados coletados.

## Funcionalidades

O programa analisa as palavras inseridas e fornece os seguintes dados:
- Lista completa com todas as 8 palavras digitadas.
- Quantidade de palavras com mais de 5 letras.
- Quantidade de palavras com 5 ou menos letras.
- Quantidade de palavras que começam com a letra "A".
- Quantidade de palavras que começam com a letra "B".
- Identificação da maior palavra digitada.
- Identificação da menor palavra digitada.
