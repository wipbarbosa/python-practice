# Review Lists 02 (review_lists_02.py)

Este script em Python foi desenvolvido para praticar a manipulação de strings, listas, laços de repetição (for) e condicionais (if). O programa coleta nomes, analisa o tamanho de cada palavra e realiza filtragens específicas.

---

## Funcionalidades

- Coleta de dados: Solicita ao utilizador a inserção de 5 nomes.
- Padronização: Converte automaticamente todos os nomes para letras minúsculas (usando .lower()).
- Exibição da Lista: Lista todos os nomes digitados no terminal.
- Análise de Tamanho:
  - Identifica e exibe nomes que possuem mais de 5 letras.
  - Encontra e exibe o maior nome digitado.
  - Encontra e exibe o menor nome digitado.
- Análise de Inicial: Identifica e exibe os nomes que começam com a letra "a".

---

## Tecnologias Utilizadas

- Linguagem: Python 3.x

---

## Como Executar

1. Certifique-se de que tem o Python 3 instalado no seu computador.
2. Guarde o código num ficheiro chamado `review_lists_02.py`.
3. Abra o terminal na pasta onde o ficheiro está guardado e execute:

```bash
python review_lists_02.py
