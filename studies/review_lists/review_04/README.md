# Analisador de Números em Python

Este é um script em Python que solicita ao usuário a digitação de 5 números válidos entre 1 e 100, valida a entrada dos dados, realiza cálculos estatísticos e exibe um resumo detalhado dos resultados.

## Funcionalidades

O programa executa as seguintes etapas e análises:
- Validação de entrada para garantir que apenas números entre 1 e 100 sejam aceitos.
- Exibição da lista completa dos 5 números válidos inseridos.
- Cálculo da soma total dos números.
- Cálculo da média aritmética dos números.
- Contagem da quantidade de números pares e ímpares.
- Identificação do maior e do menor número digitado.
