# Review Lists 01 (review_lists_01.py)

Este script em Python foi desenvolvido para praticar conceitos fundamentais de estrutura de dados (listas), laços de repetição (for), estruturas condicionais (if/else) e manipuladores de variáveis.

---

## Funcionalidades

- Coleta de dados: Solicita ao utilizador a inserção de 5 números inteiros.
- Armazenamento: Guarda os números introduzidos numa lista.
- Exibição da Lista: Percorre a lista e exibe cada elemento digitado.
- Análise Par/Ímpar: Verifica e exibe individualmente quais números são pares.
- Estatísticas:
  - Soma total dos números digitados.
  - Maior valor informado.
  - Menor valor informado.
  - Contagem total de números pares.

---

## Tecnologias Utilizadas

- Linguagem: Python 3.x

---

## Como Executar

1. Certifique-se de que tem o Python 3 instalado no seu computador.
2. Guarde o ficheiro com o nome `review_lists_01.py`.
3. Abra a linha de comandos ou terminal na pasta onde está o ficheiro e execute:

```bash
python review_lists_01.py
